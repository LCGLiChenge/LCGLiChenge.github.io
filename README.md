# Academic Homepage

A lightweight, single-page academic homepage for Chenge Li, a Zhejiang University undergraduate researcher. It uses plain HTML and CSS, has no external dependencies, and is ready for GitHub Pages.

## 1. Current content

The page has been personalized with the name **Chenge Li**, Zhejiang University email, GitHub profile, and 2024–2025 National Scholarship. Unpublished project details and optional academic metrics have intentionally been omitted.

## 2. Optional links

### CV

Put your CV in this folder as `cv.pdf`, then add a CV button to the `link-row` in `index.html`.

### Google Scholar

Do not link to someone else's profile and do not create a fake publication. The Scholar link is currently omitted; add it only after a valid public profile exists.

## 3. Publish with GitHub Pages

For this personal site at `https://LCGLiChenge.github.io`:

1. Create a **public** GitHub repository named exactly `LCGLiChenge.github.io`.
2. Upload `index.html` and, when ready, `cv.pdf` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. After GitHub finishes publishing, open `https://LCGLiChenge.github.io`.

For OpenReview verification, use that public homepage URL and make sure the page shows the same name, Zhejiang University affiliation, and verified institutional email as your OpenReview profile.

## 4. Final check before sharing

- The institutional email works.
- The GitHub link points to your account.
- The CV and Scholar buttons are either working or removed.
- Unpublished project details remain omitted until they are ready to be made public.
- The site looks correct on both a phone and a computer.
